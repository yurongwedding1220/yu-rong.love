# yu-rong.love

政憲 & 幸容 電子喜帖（自 yu-rong.love 骨架複製，內容待換成新人資料）。

## 開發

```bash
npm install
npm run dev
```

## 部署（GitHub Pages）

1. 把 `package.json` 的 `homepage`、`vite.config.ts` 的 `base` 改成你的 GitHub 帳號路徑
2. `npm run deploy`
